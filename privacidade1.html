Política de Privacidade — Manager Central

Última atualização: setembro de 2026

O Manager Central é um sistema interno de gestão operacional, manutenção e facilities, desenvolvido para uso próprio de lojas e suas equipes de gestão. Esta página explica como os dados são tratados dentro do aplicativo.

Como os dados são armazenados

Todos os dados operacionais (colaboradores, tarefas, estoque, manutenção, ativos, agenda, prevenção de incêndio) ficam armazenados localmente no dispositivo de cada loja. O aplicativo funciona de forma offline e não depende de nenhum servidor externo para operar no dia a dia.

Uso do Google Drive

O Manager Central oferece um recurso opcional de backup automático utilizando a conta do Google Drive da própria loja. Esse recurso usa o escopo mais restrito disponível do Google (drive.file no celular, drive.readonly no Gestor), o que significa que o aplicativo só enxerga e manipula os arquivos de backup que ele mesmo cria — nunca tem acesso ao restante dos arquivos pessoais da conta.

Quando ativado pelo usuário, o aplicativo:

  • Envia uma cópia de segurança (backup) dos dados da loja para uma pasta própria no Google Drive da conta conectada;
  • Permite, opcionalmente, criptografar esse backup com uma senha escolhida pelo próprio usuário, que nunca é compartilhada com o desenvolvedor nem com o Google;
  • Permite consultar o status do backup e restaurá-lo, quando solicitado explicitamente pelo usuário.

Nenhum dado é compartilhado com terceiros, vendido, ou usado para fins de publicidade.

Dados pessoais de colaboradores

O aplicativo pode armazenar localmente informações administrativas sobre colaboradores da loja (nome, cargo, escala de trabalho, registros de ausência) exclusivamente para fins de gestão operacional interna da própria empresa que utiliza o sistema.
